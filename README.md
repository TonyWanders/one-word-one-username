[![make.fun](https://make.fun/badge/u-rusdyxbt-one-word-one-username-one-reward-1a191fae.svg)](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae)

[![Reward](https://make.fun/badge/u-rusdyxbt-one-word-one-username-one-reward-1a191fae/TonyWanders/one-word-one-username/reward.svg)](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae)

A program that writes one word to `/output/entry.txt`: the entrant's own
make.fun username, and nothing else, for the make.fun competition
[One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

Run it with Python 3:

```
python3 main.py
```

It writes the username below to `/output/entry.txt` (or to the path
given as the first argument, or `$OUTPUT_PATH`). No network, no clock,
no randomness. The username is 12 characters, inside the 1 to 30 gate.

## The entry

```
anthony-orji
```
